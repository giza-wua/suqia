# توثيق منصة زِمام

- [`deployment.md`](./deployment.md) — دليل النشر الكامل (خطوة بخطوة)، بما فيه الفرق الحاسم بين Cloudflare Pages و Workers.
- [`architecture.md`](./architecture.md) — البنية العامة، قرارات المصادقة والتحديث اللحظي، الفرق بين camelCase وsnake_case، نظام النسخ الاحتياطي.
- [`schema.md`](./schema.md) — شرح كل جدول وعمود في قاعدة البيانات (`schema.sql` نفسه من غير تعليقات عمداً).
- [`api.md`](./api.md) — كل مسارات الـ API، الصلاحيات المطلوبة لكل واحد.
- [`frontend.md`](./frontend.md) — بنية الصفحات، ملفات `js/data/*.js`، الأدوات المشتركة، ملفات الـ CSS.
- [`security.md`](./security.md) — تفاصيل الأمان: كلمات المرور، الجلسات، الصلاحيات، حماية البلاغات العامة.
- [`troubleshooting.md`](./troubleshooting.md) — حلول للمشاكل الشائعة (خصوصاً لبس Pages/Workers).
- [`changelog.md`](./changelog.md) — سجل كل الإصدارات وأهم تغييراتها.

لخطوات النشر السريعة المختصرة، راجع `README.md` في جذر المشروع.
